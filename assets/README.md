# App icon

- `icon.png` — 1024×1024 master artwork
- `icon-256.png` — 256×256 preview
- `icon.ico` — multi-resolution Windows icon (16…256), generated by `scripts/makeicon`
- `cursor-tray-icon.jpg` — original generated source

`winres/` holds the sized PNGs and `winres.json` used by `go-winres` to embed the
icon into `cursor-tray.exe`. `build.bat` regenerates `icon.ico` and the `.syso`
resource objects before compiling.
